THIRD-PARTY NOTICES
====================

OpenMindAI is built on open-source software. This file lists the significant
components compiled or bundled into the Windows application, and how to
regenerate the full dependency list yourself.

This is not legal advice. It is a good-faith, generated summary intended to
give credit and help anyone auditing what ships in the binary.

SCOPE
-----

Two dependency graphs feed the shipped app:

- Rust (src-tauri/) - compiled directly into OpenMindAI.exe.
- JavaScript/TypeScript (repo root) - bundled into the embedded frontend by
  Vite at build time. Build-only tooling (TypeScript, ESLint, Prettier, the
  Tauri CLI) never ships in the executable; it's listed separately below for
  completeness, since it's still part of what you'd need to build OpenMindAI
  from source.

Every license identified across both graphs is a standard permissive one
(MIT, Apache-2.0, BSD, ISC, Zlib, Unlicense, CC0, Unicode-3.0) or MPL-2.0 -
no GPL/AGPL/copyleft dependency was found in either graph as of this file's
last regeneration.

SQLITE
------

OpenMindAI's local database is SQLite, compiled from source via rusqlite's
"bundled" feature (crate: libsqlite3-sys, MIT). SQLite itself - the actual
database engine - is dedicated to the public domain by its authors
(https://www.sqlite.org/copyright.html), not licensed under MIT/Apache-2.0
like the Rust bindings around it.

FULL TRANSITIVE DEPENDENCY LIST
---------------------------------

Beyond the direct dependencies above, the full resolved graph pulls in
roughly 413 Rust crates (Windows target) and 183 JavaScript packages - too
many to usefully hand-maintain here without the list going stale the moment
any dependency updates. Regenerate an exact, current snapshot with:

  # Rust, Windows target only, grouped by license
  cd src-tauri
  cargo metadata --format-version 1 --filter-platform x86_64-pc-windows-msvc `
    | ConvertFrom-Json `
    | Select-Object -ExpandProperty packages `
    | Where-Object { $_.name -ne "open-mind-ai" } `
    | Group-Object license `
    | Sort-Object Name

  # JavaScript, full tree including dev dependencies
  npm ls --all

At the time this file was last generated, the aggregate breakdown was:

- Rust (413 packages): overwhelmingly "MIT OR Apache-2.0" (181) and "MIT"
  (86) or an equivalent dual-license phrasing ("MIT/Apache-2.0",
  "Apache-2.0 OR MIT", etc. - SPDX expressions vary in wording across
  crates for the same effective terms); smaller groups of "Unicode-3.0"
  (18, Unicode data tables), "Unlicense OR MIT" (10), "CC0-1.0" (6),
  "MPL-2.0" (5, weak/file-level copyleft - none of these are modified by
  OpenMindAI), plus BSD/Zlib/ISC variants. No GPL/AGPL found.
- JavaScript (183 packages): "MIT" (141), "Apache-2.0" (13), "ISC" (10),
  "BSD-2-Clause" (6), "BSD-3-Clause" (3), plus a handful of single-package
  licenses ("Python-2.0" for argparse - a permissive license despite the
  name; "CC-BY-4.0" for caniuse-lite, a build-time browser-compat data
  table, not code; "BlueOak-1.0.0" for minimatch, also permissive).
