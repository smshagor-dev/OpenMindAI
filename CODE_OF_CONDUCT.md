# Code of Conduct

OpenMindAI welcomes technical discussion, bug reports, reviews, documentation work, and code contributions from people with different backgrounds and levels of experience.

## Expected conduct

Keep collaboration professional and focused on the work. Be specific when giving technical feedback, assume good intent where reasonable, and disagree with ideas without attacking the person presenting them.

Contributors are expected to:

- communicate respectfully;
- provide actionable technical feedback;
- avoid harassment, discrimination, threats, or deliberate humiliation;
- respect privacy and confidential security reports;
- avoid spam, deceptive behavior, and intentionally disruptive participation;
- follow repository contribution and security policies.

## Maintainer responsibilities

Maintainers may edit or remove comments, issues, pull requests, or other contributions that violate these expectations. Repeated or serious violations may result in temporary or permanent restrictions from project spaces.

Moderation decisions should be based on conduct in the project, not on whether someone agrees with a maintainer's technical opinion.

## Reporting conduct concerns

For ordinary project disagreements, use the relevant issue or pull-request discussion and keep the conversation technical. If a concern involves harassment, threats, privacy, or another situation that should not be handled publicly, contact the repository maintainer privately through an appropriate GitHub channel.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not this conduct process.

## Scope

This policy applies to interactions in the OpenMindAI repository and other project-managed spaces where someone is participating as a project contributor or maintainer.
